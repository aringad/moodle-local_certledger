# Changes

## 1.0.0 (2026-11-12)

First public release, derived from a plugin in production since October 2026.

- Progressive numbering of Custom certificate issues, with optional yearly restart and random check characters.
- Register with a snapshot of learner and course data, filters and export.
- Annulment with reason and optional block against re-issuing.
- Scheduled reconciliation that keeps the register in line with the issued certificates.
- Privacy API: export, and optional anonymisation on deletion requests.
